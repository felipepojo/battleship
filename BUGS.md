(https://felipepojo.github.io/battleship/) with Playwright in a fresh browser context or found in the code. Each one has a regression test that failed before its fix, and each fix is in its own commit.

## Test-only adjustment

Programmatic `focus()` in jsdom queues a 0 ms `selectionchange` timer. Two existing tests assert the exact pending timer count (`New game during the AI turn…` and `clears the pending AI timer on unmount`). These tests now run a `flushFocusTasks()` helper, which advances fake timers by 0 ms, before counting timers. The 700 ms AI timer can't fire in that window, so a leaked AI timer still fails both tests. No assertion was removed or loosened.
